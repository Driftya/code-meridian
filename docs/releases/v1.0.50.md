# CodeMeridian v1.0.50

This release enhances the Human Cognitive Seed challenge with source and test evidence, developer feedback, and safer correction handling.

## Highlights

- Added source and test evidence to Human Cognitive Seed challenges, including explicit test-gap evidence when coverage is unavailable.
- Added developer feedback options for disputing an AI-authored answer or reporting that a challenge targeted the wrong node.
- Prevented graph writes when a developer reports that the challenge targeted the wrong node.
- Updated challenge and note result contract versions to `1.1`.
- Added regression coverage for evidence validation, developer feedback, structured results, and the MCP app schema.
- Updated the MCP app and supporting package dependencies.

## Upgrade Notes

- Restart the MCP server with this version so clients receive the updated challenge app and structured result contracts.
- No graph, cache, or data migration is required.
- Clients consuming Human Cognitive Seed challenge results should support contract version `1.1` and the new evidence fields.

## Verification

- MCP server tests cover the enhanced Human Cognitive Seed challenge flow and structured results.
- `git diff --check` passes.
