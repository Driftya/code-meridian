# CodeMeridian v1.0.55

This release improves TypeScript relationship health by reducing false unresolved-call reports for library callbacks and typed function values.

## Highlights

- Classify calls through local bindings using the resolved callable signature, so callbacks implemented outside the indexed source are not reported as missing local implementations.
- Keep local callable signatures without an indexed implementation indeterminate, and retain unresolved warnings for local implementations the graph cannot represent.
- Preserve the existing resolved call relationships.

## Upgrade Notes

- Update the CodeMeridian indexer to use the corrected TypeScript relationship classification.
- Re-index TypeScript projects to refresh relationship health reports with the new classification.
- No graph contract, cache, or data migration is required.

## Verification

- TypeScript indexer tests: 92 passed.
- TypeScript compilation with `tsc --noEmit` passed.
- Driftya ClientApp full-catalog probe: unresolved calls decreased from 1,086 to 94; resolved call candidates remained at 2,564.
- `git diff --check` passes.
