# CodeMeridian v1.0.49

This release fixes MCP app integration for the Human Cognitive Seed challenge and updates the app initialization contract.

## Highlights

- Updated the Human Cognitive Seed challenge app URI to version 2.
- Updated MCP app initialization to use the current `appCapabilities` and `appInfo` parameters.
- Improved context handling for the Human Cognitive Seed challenge tools.
- Added regression coverage for the MCP app endpoints and the Human Cognitive Seed FizzBuzz flow.

## Upgrade Notes

- Restart the MCP server with this version so clients receive the updated app resources and initialization behavior.
- No graph, cache, or data migration is required.

## Verification

- MCP server tests cover the updated app URI, initialization parameters, and challenge behavior.
- Human Cognitive Seed FizzBuzz regression tests cover the corrected MCP app flow.
- `git diff --check` passes.
