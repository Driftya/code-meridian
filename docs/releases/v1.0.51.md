# CodeMeridian v1.0.51

This release fixes MCP app note-payload compatibility after the Human Cognitive Seed challenge feedback options were added.

## Highlights

- Omit optional `aiAnswerWasWrong` and `targetNodeWasWrong` fields when their values are `false`.
- Preserve sending those fields when a developer selects either feedback option.
- Keep the MCP app compatible with hosts and tests that use the original note request shape while supporting the new correction flow.

## Upgrade Notes

- Restart the MCP server with this version so clients receive the corrected MCP app resource.
- No graph, cache, or data migration is required.
