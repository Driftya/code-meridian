# CodeMeridian v1.0.42

This release focuses on graph correctness, relationship diagnostics, tool precision, indexer reliability, embedding visibility, and stronger CI coverage.

## Highlights

### Relationship Health and Graph Trust

- Added exact relationship outcome accounting across Roslyn and TypeScript indexing.
- Distinguished resolved, unresolved-local, indeterminate, external/unindexed, duplicate, and synthetic relationships.
- Added deterministic failure samples to index-run metadata.
- Improved graph drift and freshness reports with relationship completeness and actionable remediation.
- Preserved backward compatibility with older index-run metadata.
- Fixed inaccurate unresolved-relationship totals and misleading health guidance.

### Indexer Correctness

- Improved C# call resolution with receiver-safe matching.
- Fixed call edges and type-reference resolution across incremental indexing.
- Separated scan scope from ingest scope so unchanged targets can still resolve relationships.
- Preserved relationship diagnostics during incremental and diagnostic-only runs.
- Improved TypeScript relationship provenance and external-target classification.
- Fixed nested test-file role classification and partial-type handling.
- Strengthened database tracing and endpoint traversal constraints.
- Fixed `FindRelatedTestsAsync` relationship handling.

### Tool Surface Improvements

Following a complete evaluation of all 62 MCP tools:

- Canonical IDs returned by `query_codebase` can now be used directly in structural retries.
- `execute_context_workflow` correctly fails and stops when required symbol resolution fails.
- `plan_edit_route` selects anchors using symbol identity rather than unrelated summary text.
- `find_recently_changed` no longer returns operational diagnostic nodes.
- Configuration leaf usage now includes clearly labelled, confidence-capped parent-section bindings.
- Stale-knowledge analysis ignores fenced examples and explicit prohibition statements.
- Node-scoped diagnostic queries no longer suggest global indexing setup when the selected file is simply clean.
- Responsibility-slice guidance only recommends reindexing when indexed member evidence is absent.
- Improved implementation-surface targeting, connection paths, duplicate detection, ranking, and project-scoped analysis options.

### Diagnostics Lifecycle

- Excluded index-run metadata from ordinary diagnostic counts and results.
- Made diagnostic replacement project-scoped and consistent.
- Added cleanup verification instead of trusting HTTP success alone.
- Improved CLI diagnostic reporting and failure handling.
- Added integration coverage for diagnostic deletion, replacement, counting, and node-scoped lookup.

### Embedding Health and Configuration

- Added project-level embedding expectation:

  ```json
  {
    "embedding": {
      "enabled": true
    }
  }
  ```

- Updated the Meridian configuration format to version 2.
- Doctor/API/SDK/CLI now report:
  - whether embeddings are configured;
  - whether the provider is reachable;
  - provider name and dimensions;
  - number of code nodes with stored embeddings.
- Embeddings remain generated server-side for both Roslyn and TypeScript ingestion.
- Expanded embedding setup and troubleshooting documentation.

### Analysis and Planning Precision

- Propagated relationship-confidence warnings into graph-dependent tools.
- Unified structural relationship sets across risk and GDS queries.
- Improved endpoint tracing, cycles, coverage gaps, betweenness, hotspots, and responsibility slicing.
- Preserved metric ordering inside actionability groups.
- Reduced false positives from tests, configuration, generated files, ubiquitous keywords, and weak lexical matches.
- Improved keyword classification and indexed file-role configuration.

### Testing and CI

- Split oversized application and Neo4j integration test fixtures into focused suites.
- Raised non-integration coverage to at least 75%.
- Added extensive regression shields for:
  - incremental indexing;
  - Roslyn call and string resolution;
  - TypeScript relationship health;
  - configuration usage;
  - diagnostics;
  - graph freshness and drift;
  - tool targeting and workflow behavior.
- Added isolated integration-test CI coverage.
- Made npm and NuGet security audits blocking.
- Serialized CLI console-capture tests to prevent test interference.

### Security and Dependencies

- Fixed the PostCSS source-map path traversal advisory.
- Updated standalone workspace lockfiles used by CI.
- Updated `postcss` to 8.5.23 and `brace-expansion` to 5.0.8.
- Updated TypeScript to 7.0.2 and removed the obsolete `baseUrl` option.
- Updated Neo4j to 2026.06.0 and Neo4j.Driver to 6.3.0.
- Updated GitHub Actions for Node, .NET, and artifact downloads.
- Updated NSubstitute and Coverlet.
- Removed the unused Microsoft.OpenApi dependency.

## Upgrade Notes

- Run `codemeridian init .` to merge version 2 Meridian configuration defaults.
- Deploy the updated MCP server before reindexing.
- Run a full index to populate the new relationship-health metadata:

  ```powershell
  dotnet run --project tools/Indexer -- . --force-full
  ```

- To generate embeddings, configure `Embedding__Enabled=true` on the MCP server. The local indexer environment does not configure a remote server.
- Graph contract remains version 4 and cache contract remains version 3.

## Verification

- 930 .NET tests passed.
- 75 JavaScript tests passed.
- Roslyn and TypeScript indexer suites passed.
- npm audits report zero vulnerabilities.
- NuGet reports no vulnerable packages.
- All three standalone JavaScript workspace audits, builds, and test suites pass.
