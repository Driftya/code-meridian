# MCP 2 Local Adoption Notes

## Scope

This working-tree release moves CodeMeridian from `ModelContextProtocol.AspNetCore` 1.4.1 to the stable 2.x package line and adopts selected MCP 2 capabilities without changing the configured HTTP endpoint or requiring a graph re-index.

Resolved package versions:

- `ModelContextProtocol.AspNetCore` 2.0.0
- `ModelContextProtocol.Extensions.Tasks` 2.0.0
- `ModelContextProtocol.Extensions.Apps` 2.0.0

Locally tested protocol paths:

- modern `2026-07-28` stateless `server/discover`
- down-level `2025-11-25` `initialize`

## Added

- Explicit safety annotations and titles for all 62 MCP tools.
- Versioned structured output for `find_connection` and the three client-extension contract tools, with useful Markdown retained.
- Private five-minute `tools/list` caching hints.
- Bounded per-tool activity, counter, histogram, and structured logging.
- Optional MCP Tasks for keyword rebuild/classification, including cancellation, TTL, capacity, duration, result-size, health, and metrics controls.
- Optional read-only MCP Apps for the client-extension contract and graph connection views, disabled by default.
- Modern/down-level raw-wire baselines, JSON Schema validation, and browser-DOM security/accessibility tests.

## Compatibility Notes

- The existing `/sse` URL remains a stateless Streamable HTTP endpoint; stateful SSE is not restored.
- Existing tool names and JSON arguments are unchanged.
- Older or non-structured clients keep useful text results.
- Tasks are client-opted; ordinary calls continue to work.
- Apps are disabled by default and do not affect non-App clients.
- No `[McpHeader]` parameter mirror is shipped. The initial optional `projectContext` pilot was removed because the SDK mirror contract made ordinary calls fail when the header was absent.
- Task state is process-local and lost on restart. Multi-principal and multi-replica guarantees are not provided.

## Configuration And Rollback

- Disable Tasks with `Mcp__Tasks__Enabled=false`.
- Disable Apps with `Mcp__Apps__Enabled=false`.
- Task runtime limits live under `Mcp:Tasks` in `src/McpServer/appsettings.json`.
- Rollback does not require clearing or rebuilding the Neo4j graph.

## Acceptance Still Required

Before deployment, run the plan's live acceptance batch with VS Code, Codex, and Continue, exercise real keyword task cancellation, and verify optional App rendering in every host that will be claimed as supported.
