# CodeMeridian v1.0.48

This release fixes a server error that stopped C# indexing when the Roslyn indexer sent a batch of relationships with edge evidence.

## Highlights

- Fixed JSON deserialization for the edge-ingestion request after edge evidence added a second public constructor. The API now selects the compatible constructor explicitly for both single-edge and bulk requests.
- Preserved support for older edge payloads and the newer evidence fields, including resolver details and source locations.
- Marked the completed edge-level relationship evidence plan as done.

## Upgrade Notes

- Restart the MCP server with this version before retrying an index run that failed at `/api/v1/knowledge/nodes/edges/bulk` with HTTP 500.
- No graph or cache migration is required for this fix. A failed run can be retried with the normal indexing command.

## Verification

- A regression test reproduced the `System.Text.Json` constructor error before the fix and now deserializes a bulk payload containing both legacy and evidence-bearing edges.
- The MCP server test suite passes: 132 passed, 6 skipped.
- `git diff --check` passes.
